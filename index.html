Política de Privacidade

// Última atualização: 2026

Esta Política de Privacidade descreve como os aplicativos desenvolvidos por Marcos Jesus Dev CwB coletam, usam e protegem suas informações.

1. Dados coletados

Nossos aplicativos podem coletar dados não pessoais para fins de publicidade (via Google AdMob), como identificadores anônimos do dispositivo.

2. Armazenamento local

Todos os dados gerados pelo uso dos apps são armazenados localmente via AsyncStorage e não são compartilhados com terceiros.
